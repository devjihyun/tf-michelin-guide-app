이 문서는 [unified_spec.md](/c:/Users/jihyun.kim/toy/docs/unified_spec.md) 기준의 화면 정보 구조다.

## `/access`

- 인트로 화면 v2
- 로그인 유지 확인
  - 세션이 유효하면 `/restaurants` 바로 이동
- 계정 로그인
  - 닉네임
  - 패스워드
  - 로그인
- 최초 계정 등록
  - 초대코드 입력
  - 회사 / 조직 확인
  - 닉네임 입력
  - 패스워드 입력
  - 계정 등록
- 계정 등록 성공 시 `/restaurants` 이동
- 로그아웃 상태에서 재접속 시 초대코드 재입력 없이 계정 로그인
